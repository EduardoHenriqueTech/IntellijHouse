Capturas das telas implementadas (1366×850 e celular), feitas com os dispositivos e rotinas de exemplo do projeto:

| Arquivo | Tela | Público |
|---|---|---|
| `01-visao-geral.png` | Painel com indicadores, ambientes e banner de sugestão da rotina | Morador |

## Fluxo de navegação
`Visão geral` → `Dispositivos` · `Assistente virtual` · `Ambientes` · `Atividade recente` · `Rotinas aprendidas`, e do menu lateral para a `Área administrativa` (e de lá, de volta ao painel ou para o Swagger).

## Entregando no Figma / Canva (exigência do roteiro)
O roteiro pede protótipo em Figma, Adobe XD ou Canva. Estas capturas **não são um arquivo Figma**: para cumprir o item, crie um arquivo no Figma (ou Canva), importe os PNGs como molduras, adicione as setas de navegação do fluxo acima e anote a paleta (fundo `#1C1C1F`, menu lateral `#161618`, cartões `#212125`, bordas `#2E2E34`, texto `#F1F1F2`, destaque âmbar `#E8B04A`, verde de status `#58B882`, vermelho de erro `#E5645F`) e a fonte (Inter, com Segoe UI e a fonte do sistema como reserva). Guarde o link do arquivo para mostrar à banca.
